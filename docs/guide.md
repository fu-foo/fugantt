## 表を編集する

矢印で動き、Enter（または F2・ダブルクリック・そのまま打つ）で編集、Esc で取り消し。
Enter で確定すると下へ、選択肢と日付だけは右へ進む。Tab は右へ。計算で決まる列（日数・差異）は飛ばす。

- **⌘Enter / Ctrl+Enter** で下に行を足して、そのまま名前を打てる
- **⌥→ / Alt+→** で子にする、**⌥← / Alt+←** で戻す。**⌥↑↓ / Alt+↑↓** で並べ替え
- **右クリック**で同じ操作のメニュー。**行の色**（背景・文字）もここから

キーの一覧は[リファレンス](reference.md#キー操作)に。`⌘` と `Ctrl` はどちらでも効く。

### 日付の入れ方

日付は**桁数だけで決まる**。

| 打つ | 入る |
| --- | --- |
| `5` | 当月の5日 |
| `305` | 当年の3月5日 |
| `1225` | 当年の12月25日 |
| `20261225` | そのまま |
| `8/5`、`2026-08-05` | そのまま。全角でもいい |

**来月へは送らない。** 12/28 に `3` と打てば 12/03（過去）になる。

### 列

列幅は**見出しの右端をつまんで**変える（このブラウザにだけ残る。ダブルクリックで戻る）。
表とチャートの境目も同じように動く。計算で決まる列（予定日数・遅れ・差異）は見出しが淡い。

### 取り消し

**⌘Z / Ctrl+Z** で戻し、**⌘Y / ⌘⇧Z / Ctrl+Y** でやり直す。戻せるのは**この画面でした変更**だけ。

- 値の変更、**行の追加**（足した行を消す）、**並べ替え**（元の親と位置に戻す）を戻せる
- 間に他の人が同じセルや行を触っていたら、止めて知らせる
- 中身の入った行は、取り消しでは消さない
- **削除は戻せない。** 消す前に確認が出る
- リロードすると履歴は消える

## チャート

- **左上の「今日」**で今日に戻る
- **表もチャートも、つかんで左右に引ける。** 少し動かすまではクリックなので、セルもバーも今までどおり選べる
- **バーはドラッグで動く。** 端（7px）をつまむと開始日・終了日だけ伸縮する。実施バーも同じ。
  進行中（実施終了が空）の行は、横に動かしても終了日を作らない
- **進捗は予定バーの中のつまみ**で変える
- **バーにポインタを合わせる**と、日付のほかに設定で選んだ項目が出る（表から外した列や独自項目も選べる）
- **集計行（親）のバーは既定で出さない。** 畳んだ親は子の代わりにバーを出し、子の担当者の休みも出る。
  親のバーを常に出したければ、チャート左上の`表示`から（自分の画面だけ）

## 納期

**「この日までにやればOK」**のタスクは、**納期**だけを入れる。

チャートには**行の上端に下向きの印**が出る。バーは引かれず、空き検索でも**その人の日数を使わない**。

納期と予定は**両方入れてもいい**。「客先納期は 11/30、うちの予定は 11/10〜11/25」は1行で持てて、
バーの端と印のあいだが余裕として見える。

集計行の納期は**子の最大**。遅れは子から吸い上げる（子が納期を落とせば、親も遅れになる）。

## 予定と実施

日付は **納期・予定開始・予定終了・実施開始・実施終了** の5つ。**開始差異**と**終了差異**は毎回引き算で出す。
チャートは予定が枠、実施がその下の実線、納期が上端の印。

### 進捗

新しいプロジェクトは**「ステータスに連動」**で始まる。ステータスを変えると、その状態に決めた進捗が入る
（完了→100%、未着手→0%。進捗を決めていないステータスは手入力のまま）。
数字を手で入れたいなら、設定の「進捗の入れ方」で「手入力」にする。

どちらでも、100% にすると実施終了が空なら今日が入る。進捗の塗りは予定バーの中に出る。

### 待ち

止まっていた期間を、**期間と理由**で入れる。終わりを空けておけば、今日まで待っている扱い。
待ちの日数は、日数・遅れ・空き検索のどれからも外れる。チャートでは斜線で出る。
**子のタスクに入れる**（集計行では入れられない）。

### コメント

ダイアログで書く。Enter は改行、**⌘Enter / Ctrl+Enter で保存**。500文字まで。
表には1行で出て、全文はマウスを乗せると出る。

### 休暇と出社

スケジュール画面のボタンから。休暇は人につくので、その人が出てくる全プロジェクトに効く。
「土日だがこの日は出る」は出社で入れる。

## 予定進捗と遅れ

### 予定進捗

**この日までに何%**を、待ちと同じダイアログで入れる。その日を過ぎて実進捗が届いていなければ赤くなる。

- 見るのは入れた日だけ。8/20 に 30%、8/28 に 100% と入れたなら、その2日で判定する
- チャートでは、足りない分が塗りの続きの帯として出て、端に `8/5 50%` と書く。帯の端は日付ではなく、
  バーの 50% の位置
- 達成すると帯は消える。まだ来ていない予定は細い印で出る。`表示`から消せる
- **入れなければ、進捗では遅れにならない**

### 遅れの列

**遅れは2列**（タスクのすぐ右）。遅れている行には赤い印が付く。

| 列 | 赤くなるとき |
| --- | --- |
| **予定遅れ** | 入れた予定進捗に届いていない／予定終了を過ぎて実施終了が空（期限超過） |
| **納期遅れ** | 納期を過ぎて終わっていない |

納期を入れていない行は納期遅れが空、予定を入れていない行は予定遅れが空。

**終わってから遅れたと分かった行は「遅れた」。** 納期より後に終わった行は、淡い印で「遅れた」と出て、赤くはならない。
絞り込みの「遅れ」はいま遅れている行だけ。振り返るときは「遅れた」を選ぶ。

なぜ2列なのか、なぜ終わった遅れを赤くしないのかは[考え方](design.md#遅れ)に。

## 空き検索

「山田は今月どれくらい空いているか」を、月単位・任意の範囲で出す。

| 担当者 | 稼働可能日数 | 経過済 | 割当済 | 空き日数 | 重複 | |
| --- | --- | --- | --- | --- | --- | --- |
| 佐藤 | 21日 | 10日 | 11日 | **0日** | 5日 | 重複: 8/24〜8/28 |
| 山田 | 21日 | 10日 | 0日 | **11日** | — | 空き日数: 8/17〜8/31 |
| （未割当） | — | — | 6日 | — | — | |

| 列 | 意味 |
| --- | --- |
| 稼働可能日数 | 範囲の中で、休日と休暇を除いた日数。**経過済 ＋ 割当済 ＋ 空き日数** |
| 経過済 | 今日より前の日 |
| 割当済 | 今日から先で、予定バーが1本でもかかっている日 |
| 空き日数 | 今日から先で、何も入っていない日。日付も出る |
| 重複 | 2本以上のバーが重なっている日。日付も出る |

- 同じ日に3件あっても1日と数える
- 数えないもの: 終わったタスク、集計行、納期しかない行、待ちの日
- **未割当**（担当者が空のタスク）も1行で出る
- **飛び飛びにやるタスクは子に分ける。** 1本のバーは端から端まで全部の日を押さえる。
  親を「そのタスク」、子を「1回ごとの着手」にすれば、押さえるのは子の日だけになる。
  止まっているだけなら、分けずに待ちを入れる

**全体の空き検索**（左のメニュー）は同じ表を、自分が開けるプロジェクトすべてで出す。
休みは会社の暦（土日と全体の設定の祝日）と、その人の休暇で数える。

## 統計とタスク変更履歴

**統計**（ドロワーの「統計」）はそのプロジェクトの数字。集計行は数えない。

| | |
| --- | --- |
| タスク・平均進捗 | 件数と、進捗の平均 |
| 遅延中・遅れていない | いま遅れている行（予定遅れ、または終わっていない納期遅れ）の数と、それ以外 |
| 作業の遅れ | 待ちを除いた遅れの日数 |
| ずれの内訳 | 作業の遅れ ＋ 待ち ＝ ずれ。待ちは理由ごとに出る |
| ステータス・担当者 | それぞれの件数。担当者にはステータスの内訳と平均進捗も |

同じ数字を API で取るなら [`/api/summary`](reference.md#api)。

**タスク変更履歴**は、誰がいつ、どの行のどの値を変えたか。API トークンでの変更は `API <トークンの用途>` と出る。

## 絞り込み

見出しの上に、列ごとに1つ。複数埋めれば AND。

- 文字の列は、含む行に絞る
- 日付と数値は、欄の左のボタンで**以上・以下・一致・超過・未満**を選ぶ（`100以下` `>=3` と打っても同じ）
- 遅れの2列は**遅れ／順調**から選ぶ。納期遅れには**遅れた**もある

## 設定

会社として決まっていることは**全体**（管理者）に、その計画のことは**プロジェクト**に置く。

| 全体（管理者） | プロジェクト |
| --- | --- |
| 祝日・休業日 | この現場だけの休み／「全体は休みだがここは動く」日 |
| 担当者の色 | この計画に出てくる担当者と、その並び順 |
| 担当者の休暇・出社 | 列・独自項目・表示・メモ・メンバー |
| 既定のステータス（作成時に写す） | そのプロジェクトのステータス |
| パスワードの決まり・アプリ名・元号・言語 | API トークン（そのプロジェクト用） |
| バックアップの作成・復元、全プロジェクト用の API トークン | |

- **日本の祝日は勝手に入る。** 去年・今年・来年の分を、起動時と日付が変わったあとに足す。
  一度入れた年は二度と足さないので、消した祝日は戻ってこない。自分で祝日を入れていた年にも手を出さない
- プロジェクトの祝日は「全体 ＋ この計画で足した日 − この計画で外した日」
- ステータスは作成時に全体から写す。全体を直しても、既にあるプロジェクトは変わらない

### プロジェクトの設定

| | |
| --- | --- |
| 表示 | 日数から除く日、年度の開始月、和暦、四半期、1日の幅 |
| 列 | 表示・幅・並び順。組み込み列と独自項目をまとめて扱う。タスク名は先頭で固定 |
| チャートマウスオーバー時の表示 | バーにポインタを合わせたときに出す項目。表から外した列も選べる |
| ステータス | 名前・色・その状態が意味する進捗（空なら手入力のまま）・並び順 |
| 独自の項目 | フリー・選択・フリー＋選択・日付・数値。名前はあとから直せる。種類を変えられるのは、その列が空のときだけ |
| バーの色 | 予定・完了分・実施・集計行・遅れ・今日・土曜・日曜・祝日・休暇・待ち |
| メンバー | オーナー・編集者・閲覧者 |
| API トークン | このプロジェクトだけを開けるトークン（[リファレンス](reference.md#api)） |

**新しい計画の列**は、タスク・予定遅れ・納期遅れ・担当者・ステータス・納期・予定開始・予定終了・
実施開始・実施終了・コメントの11列。日数・差異・実進捗・待ち・予定進捗は隠れていて、「列」で出せる。

## 書き出しと取り込み

ドロワーの「データの入出力」から。

| | |
| --- | --- |
| Excel で書き出す | 画面と同じ列と、その右にセルで描いたチャート。読むため |
| JSON で書き出す（タスク＋設定） | プロジェクトの全部（設定・ステータス・担当者・暦・独自項目・タスク） |
| JSON で書き出す（タスク） | タスクだけ |
| JSON を取り込む（全置換） | JSON の中身でプロジェクトを置き換える |

> [!WARNING]
> **取り込むと、タスクはすべてファイルの中身に置き換わる。ファイルに無い行は消える。**
>
> - 行を見分けるのは `id`。ファイルの `id` がこのプロジェクトの行と同じなら、その行を書き換える。
>   `id` が無い行・知らない `id` の行は、新しい行として足す
> - そのため、**`id` を省いたファイルを今あるプロジェクトに取り込むと、今の行はすべて消えて、
>   ファイルの行が新しい行として入る**（変更履歴は別の行のものになる）
> - `tasks` が空、または無いファイルを取り込むと、タスクは全部消える
> - 画面からは確認が出るが、[API](reference.md#api) での書き戻しは確認なしで同じことをする
>
> 取り込む前に、JSON で書き出して控えを取っておく。

**よくある使い方**

- **書き出して、直して、戻す。** 書き出したファイルには `id` が入っているので、そのまま戻せば同じ行が書き換わる。
  タスクだけのファイルでもいい（設定は変わらない）
- **手で書いたファイルから新しく作る。** 空のプロジェクトに取り込む。`id` は省いていい
- **ほかのサーバーへ移す。** タスク＋設定で書き出して、移した先の空のプロジェクトに取り込む

タスク以外の部分（設定・ステータス・担当者・祝日・独自項目）は、**ファイルにある部分だけ置き換え、
無い部分は今のまま**。休暇は全社のものなので、ファイルにある分を足すだけで、ほかの休暇は消さない。

ファイルの形は[リファレンス](reference.md#json-の形)に。

## 外観（自分の設定）

**テーマ**は自動（OSに合わせる）／明るい／暗い。**自分用の CSS** も書ける。どちらも自分の画面にだけ効く。
計画の色（バー・ステータス・担当者）はプロジェクトのものなので、ここでは変わらない。

自分の CSS は最後に読み込まれるので、ここに書いたものが勝つ。2万文字まで、`@import` は無効。
外の画像やフォント（`url(https://…)`）は読まない。

```css
.fg-bar { border-radius: 0 }        /* バーの角を落とす */
.fg-row.fg-data { font-size: 13px } /* 表を詰める */
```

## 言語

既定は日本語。決まる順は、その人の設定 → 全体の設定 → ブラウザの言語（`Accept-Language`）。

ステータス・独自項目・担当者・プロジェクトの名前など、利用者が付けた名前は訳さない。
